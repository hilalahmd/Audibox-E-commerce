# 🎧 AudioBox — E-Commerce Platform

🔗 **Live Demo:** [Click here to view](https://audibox-e-commerce-erlk.vercel.app/products)

## 📌 About
A fully functional e-commerce platform built with the MERN stack featuring product listings, cart management, order processing, and secure authentication.

## 🛠️ Tech Stack
- **Frontend:** React.js, Redux, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Auth:** JWT, HttpOnly Cookies, bcrypt
- **Payment:** Stripe
- **Tools:** Git, GitHub, Postman, Axios

## ✨ Features
- Product listings & search
- Cart & order management
- JWT-based secure authentication
- Responsive UI
- Stripe payment integration
