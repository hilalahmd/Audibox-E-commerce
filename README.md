## Overview

Audibox is a full-stack e-commerce platform supporting dynamic product catalogs and end-to-end checkout workflows for 200+ product listings, with a RESTful API covering catalog management, cart logic, authentication, and order processing.

<br>

## Key Features

- 💳 **Payments** — Integrated Stripe and Razorpay, supporting both local and international transactions
- 🔐 **Secure Authentication** — JWT with HttpOnly cookies, bcrypt password hashing, and role-based access control for Admin and User
- 🛡️ **Security Hardening** — Protected with Helmet, express-mongo-sanitize, and express-rate-limit against common web vulnerabilities
- 📸 **Image Pipeline** — Multer + Cloudinary integration for optimized product image uploads, significantly reducing server storage load
- 📊 **Admin Dashboard** — Business metrics and sales data visualized with ApexCharts
